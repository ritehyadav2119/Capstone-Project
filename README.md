# Intelligent Document Summarization System Using Generative AI

## Overview
An AI-powered application for document summarization, document chat, analytics, quiz generation, flashcards, and PPT generation.

## Features

- User Authentication
- PDF/DOCX/TXT/CSV/XLSX Support
- AI Summarization
- AI Chatbot
- Analytics Dashboard
- Quiz Generator
- Flashcard Generator
- PPT Generator
- PDF/DOCX/TXT Export

## Technologies

- Python
- Streamlit
- LangChain
- Groq
- FAISS
- HuggingFace Embeddings
- SQLite
- Plotly
